# تحسين الأداء V56.1 — مجموعة النسيم

## ما الذي تغير؟
- إضافة سجل تشخيص للطلبات التي تستغرق ثانية أو أكثر، مع تسجيل الطريقة والمسار والمدة ورمز الاستجابة فقط، دون تسجيل محتوى الطلب أو بيانات العملاء.
- إضافة فهارس SQLite لأكثر حقول البحث والفرز شيوعًا: الحجوزات والتاريخ والحالة، العملاء وأرقام الهواتف، التحصيلات، الاستفسارات والمتابعات، الخزنة، وسجلات المراجعة وأوامر الشغل.
- ضبط ذاكرة SQLite المؤقتة إلى نحو 32 ميجابايت، مع الاحتفاظ بوضع WAL و`busy_timeout` الحالي.
- إبطاء التحديث الدوري للتنبيهات والتحصيل من 30 إلى 60 ثانية لتقليل الطلبات الخلفية. يظل التحديث متوقفًا في الخلفية عند إخفاء صفحة المتصفح وفق الكود الموجود.

## قبل التركيب
1. أوقف السيرفر.
2. انسخ مجلد `data` كاملًا إلى مكان آمن، بما في ذلك `nasim.sqlite` وأي ملفات `-wal` أو `-shm` إن وجدت بعد إيقاف السيرفر.
3. فك الضغط في مجلد جديد، ولا تحذف النسخة الحالية.
4. انقل قاعدة البيانات الحالية إلى مجلد `data` في النسخة الجديدة، ولا تبدأ بقاعدة فارغة.
5. شغّل السيرفر بالطريقة المعتادة.

## متابعة الأداء
راقب نافذة السيرفر. أي طلب يستغرق ثانية أو أكثر سيظهر كسطر يبدأ بـ`[أداء]` ويعرض مسار الطلب ومدته ورمز الاستجابة. أرسل هذه الأسطر عند استمرار البطء؛ لا تحتوي على محتوى الحجز أو كلمات المرور.

## الاختبارات التي أجريت
- اجتاز `node --check server.js`.
- اجتاز `node --check public/app.js`.
- تم التحقق من سلامة أرشيف ZIP بعد إنشائه.

## حدود الاختبار
لم يُنفذ اختبار ضغط فعلي على 6–15 مستخدمًا متزامنًا، ولم تُختبر قاعدة بيانات المنشأة الحية هنا؛ لذلك لا يمكن ضمان انعدام التهنيج تمامًا قبل قياس الأداء أثناء الاستخدام الحقيقي. هذه النسخة تضيف تحسينات آمنة وأدوات تشخيص لتحديد أي اختناق متبقٍ بدقة.
