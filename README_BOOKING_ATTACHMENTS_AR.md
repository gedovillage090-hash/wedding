# مرفقات الحجز

- يمكن اختيار مرفقات عند إنشاء الحجز، وسترفع بعد حفظ الحجز.
- من شاشة تعديل الحجز يمكن رفع مرفقات إضافية، وفتح/تنزيل المرفقات المحفوظة، أو حذفها بصلاحية التعديل.
- الأنواع المسموحة: PDF, JPG, PNG, WEBP. الحد الأقصى 10 MB للملف.
- الملفات تخزن محليًا في data/booking-files وترتبط برقم الحجز.
- عند نقل النظام لجهاز آخر، يجب نسخ مجلد data/booking-files مع قاعدة البيانات.
