# صلاحية إدارة العروض

تمت إضافة صلاحية مستقلة باسم «العروض» إلى شاشة «الموظفون والصلاحيات».

- لتفعيلها لموظف: سجّل الدخول كمدير نظام، افتح «الموظفون والصلاحيات»، اختر المستخدم في «تعديل صلاحيات مستخدم موجود»، فعّل «العروض»، ثم اضغط «حفظ الصلاحيات».
- لإيقافها: أزل علامة الاختيار من «العروض» واحفظ الصلاحيات.
- مدير النظام يحتفظ بصلاحياته الكاملة.
- تم تطبيق التحقق في الواجهة والخادم لإنشاء العروض وتفعيلها أو إيقافها.

مهم: خذ نسخة احتياطية من قاعدة البيانات الحالية قبل الاستبدال، ولا تستبدل قاعدة بياناتك بقاعدة البيانات المرفقة في الأرشيف؛ احتفظ بقاعدة بيانات التشغيل الحالية.
