إصلاح حفظ تعديل الحجز — V43

- تم إصلاح مرجع حقل الملفات داخل نموذج تعديل الحجز: كان كود الحفظ يقرأ متغيرًا غير معرّف (newFilesInput) بدل حقل الملفات الموجود داخل نافذة التعديل، ما كان قد يؤدي إلى توقف المعالجة بعد طلب الحفظ.
- أضيفت رسائل أوضح عند فشل تحديث بيانات الحجز أو غرف العروسة، مع تسجيل الخطأ في Console.
- تم الحفاظ على أسعار الفرد الإضافي: المسائي 60 جنيهًا والنهاري 75 جنيهًا.
- لم تُضمّن قاعدة البيانات في الحزمة لتجنب استبدال قاعدة البيانات الفعلية.
- تم فحص صياغة JavaScript فقط؛ يلزم اختبار الحفظ على نسخة احتياطية من قاعدة البيانات الفعلية.
