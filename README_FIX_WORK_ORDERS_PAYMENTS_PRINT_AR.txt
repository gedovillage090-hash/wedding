إصلاح أوامر الشغل والتحصيل والدفعات والطباعة — نظام النسيم

الملفات المصححة في هذه الحزمة: server.js و public/app.js. لا تحتوي الحزمة على ملف .env أو مفاتيح سرية.

الأخطاء التي يعالجها التعديل:
1) /api/collection كان يعيد صفًا لكل دفعة بدل صف واحد لكل حجز؛ الآن يجمع المدفوعات ويعرض المبلغ المحصل والمتبقي مرة واحدة لكل حجز.
2) /api/collection/:id/history كان يعيد مصفوفة خام بينما الواجهة تنتظر payments و paid_total و recorded_types و booking؛ الآن يتوافق شكل الاستجابة مع الواجهة.
3) أضيفت مسارات أوامر الشغل: عرض أوامر الشغل والحجوزات المؤكدة، البحث برقم الموبايل، إصدار/تحديث أوامر القاعة والمطبخ والمخزن، إسناد المتعهد، تغيير الحالة وسجل التعديلات.
4) أضيفت مسارات ربط إيصالات المصروفات وسجل الخزنة بالطباعة، كما عُدلت الطباعة لفتح نافذة الطباعة قبل طلب الشبكة لتجنب منع النوافذ المنبثقة.
5) يعالج رد التأمين كحركة مصروف في الخزنة، لا كمقبوض.

قبل النشر:
- احتفظ بنسخة من server.js و public/app.js الحاليين.
- لا ترفع .env أو SUPABASE_SERVICE_ROLE_KEY إلى GitHub.
- لا تنفذ SQL ولا تمسح أو تعِد استيراد أي بيانات.
- نفّذ npm run check من جذر المشروع.

لنشر التحديث عبر GitHub:
1) استبدل server.js في جذر المستودع بهذا الملف.
2) استبدل public/app.js بهذا الملف.
3) Commit ثم Push إلى الفرع المتصل بـ Vercel.
4) انتظر حالة Ready، ثم اختبر /#/work_orders و /#/finance.

ملاحظات الاختبار:
تم فحص صياغة JavaScript باستخدام node --check. لا يمكن التحقق من بيانات مشروع Supabase المنشور من بيئة إنشاء هذه الحزمة، لذا يجب اختبار المسارات بعد النشر.
