تحديث واجهة عربية وأوامر الشغل — النسخة 48

التعديلات:
- إظهار وقت بداية الفرح فقط في قائمة أوامر الشغل واختيار الحجز وورقة أمر الشغل المطبوعة.
- إزالة وقت نهاية الفرح من أعمدة تصدير أوامر الشغل إلى ملف الجداول.
- تحويل أسماء ملفات تصدير ميزان المراجعة وقائمة الدخل ودفتر الأستاذ إلى أسماء عربية.
- تحويل أزرار وعبارات تصدير التقارير المحاسبية إلى إكسل بدلًا من الكتابة الإنجليزية.
- ترجمة أنواع الحسابات وحالات القيود المعروفة في شاشات المحاسبة.
- إزالة عرض اسم المستخدم الافتراضي المكتوب بالإنجليزية من شاشة الدخول.

مهم:
- لم يتم تغيير أسماء الحقول الداخلية أو قيم قاعدة البيانات حتى لا تتعطل البيانات القديمة والتكاملات.
- يجب تجربة النسخة على نسخة احتياطية من قاعدة البيانات قبل استبدال النسخة المستخدمة فعليًا.
- تم فحص الصياغة البرمجية لملفي الواجهة والخادم، ولم يُجرَ اختبار شامل داخل المتصفح على قاعدة البيانات الفعلية.
