تحديث تحسين الاستجابة — V56

التعديلات:
1. خفض تحديث التنبيهات التلقائي من كل 8 ثوانٍ إلى كل 30 ثانية، وإيقاف التحديث عندما تكون نافذة المتصفح مخفية، ومنع بدء تحديث جديد قبل انتهاء السابق.
2. خفض تحديث بيانات صفحة التحصيل من كل 8 ثوانٍ إلى كل 30 ثانية، مع إيقافه عند إخفاء نافذة المتصفح ومنع تداخل عمليات التحديث.
3. إضافة مهلة انتظار لقاعدة بيانات SQLite مدتها 5 ثوانٍ عند انشغال قاعدة البيانات، مع الإبقاء على WAL والمفاتيح الخارجية.
4. تحسين عرض بعض تفاصيل التنبيهات المسجلة بصيغة JSON، وإضافة ترجمة عربية لإجراء الحذف وبعض حالات الدفع.

مهم:
- هذه تحسينات أولية تقلل الطلبات المتكررة وتساعد في التعامل مع انشغال قاعدة البيانات، لكنها لا تثبت وحدها أن كل أسباب التهنيج انتهت.
- لم يتم نقل قاعدة البيانات أو تعديل بيانات الحجوزات.
- الاختبارات المنفذة: فحص بناء JavaScript باستخدام node --check، وفحص npm run check.
- قبل الاستبدال، أوقف السيرفر وخذ نسخة احتياطية من مجلد data بالكامل. لا تستبدل قاعدة البيانات بقاعدة فارغة.
