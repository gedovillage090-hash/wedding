تحديث عرض «خصم على الباكدج + وجبات هدية»

- من قسم العروض اختر النوع الجديد.
- اختر باكدج القاعة من القائمة، وحدد الخصم كنسبة أو مبلغ ثابت، ثم عدد الوجبات الهدية وفترة العرض.
- يظهر العرض للموظف عند تطابق القاعة/الباكدج/تاريخ المناسبة، ويجب اختياره يدويًا.
- عدد الوجبات الهدية معلومة تشغيلية فقط ولا يضاف سعرها إلى الفاتورة ولا يغيّر حساب إجمالي الحجز.
- تمت إضافة أعمدة متوافقة تلقائيًا عند تشغيل السيرفر، دون حذف أعمدة أو بيانات موجودة.

ملاحظة: تم فحص صياغة JavaScript باستخدام node --check. لم يتم إجراء اختبار متصفح متكامل في هذه البيئة.


تحديث: في عرض «خصم على باكدج القاعة ووجبات هدية» يظهر الآن اختيار باكدج البوفيه المستهدف: باكدج واحد أو كل باكدجات البوفيه. يُطبّق العرض فقط إذا كان الحجز يحتوي على البوفيه المحدد، وتظل الوجبات الهدية مرتبطة بالعرض.
