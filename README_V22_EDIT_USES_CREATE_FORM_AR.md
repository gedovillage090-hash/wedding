نسخة V22 — تعديل الحجز بنفس نموذج الإنشاء

- زر تعديل الحجز يفتح نموذج إنشاء الحجز الأصلي نفسه داخل شاشة الحجز الكاملة، بدل نموذج تعديل منفصل.
- يتم تحميل بيانات العميل والتاريخ والقاعة والباكدج والبوفيه والإضافات وغرف العروسة إلى الحقول الأصلية.
- تستخدم المعاينة الحية الأصلية للفاتورة، مع حفظ التغييرات إلى الحجز الأصلي عبر API التعديل.
- تم فحص syntax لملفي JavaScript والخادم وسلامة ملف ZIP.
- لم يتم إجراء اختبار متصفح end-to-end. خذ نسخة احتياطية من قاعدة بيانات التشغيل الحالية قبل استبدال الملفات، ولا تستبدل قاعدة البيانات المرفقة بقاعدة بياناتك الحية.
