# الإصدار 54 — ترتيب أسماء نموذج الاستفسارات والمتابعة

تم تعديل ترتيب الحقول الظاهرة في نموذج تسجيل استفسار جديد ليكون:
1. اسم المتعاقد.
2. اسم العريس.
3. اسم العروسة.

تم الإبقاء على أسماء الحقول الداخلية كما هي لضمان توافق الحفظ وقاعدة البيانات، مع تعديل التسمية الظاهرة للمستخدم فقط.

## التحديث
1. أوقف البرنامج.
2. خذ نسخة احتياطية من مجلد `data` وقاعدة البيانات `nasim.sqlite`.
3. حدّث ملفات البرنامج من هذه النسخة مع الاحتفاظ بقاعدة البيانات الحالية.
4. أعد تشغيل `START_WINDOWS.bat` ثم حدّث صفحة الاستفسارات والمتابعة.
