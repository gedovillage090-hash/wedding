- السماح بحفظ عرض «خصم على الباكدج + وجبات هدية» عند اختيار «كل الباكدجات» في حقل باكدج القاعة.
- عند اختيار كل الباكدجات، يتم حفظ hall_package_id فارغًا، وهو ما يجعل العرض صالحًا لكل باكدجات القاعات المطابقة لباقي الشروط.
- إزالة شرط التحقق الذي كان يجبر المدير على اختيار باكدج قاعة بعينها.

1. أوقف السيرفر الحالي.
2. خذ نسخة احتياطية من مجلد المشروع وقاعدة البيانات data/nasim.sqlite.
3. فك ضغط النسخة المصححة في مجلد منفصل.
4. للحفاظ على البيانات الحالية، انسخ قاعدة البيانات الحالية إلى مجلد data في النسخة الجديدة بعد الاحتفاظ بنسخة احتياطية.
5. شغّل START_WINDOWS.bat ثم افتح صفحة العروض وجرب اختيار «كل الباكدجات» وحفظ العرض.
