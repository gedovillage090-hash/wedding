# تحديث حساب الأفراد الإضافيين

- عند اختيار باكدج يسع 250 فردًا وكتابة عدد حضور 260، يحسب النظام 10 أفراد إضافيين × 60 جنيه = 600 جنيه.
- تُضاف قيمة الأفراد الإضافيين إلى إجمالي المناسبة قبل حساب خدمة 15%.
- لا تُحسب رسوم إضافية إذا كان عدد الحضور مساويًا لسعة الباكدج أو أقل منها.
- ينطبق الحساب عند إنشاء الحجز وعند تعديل عدد الأفراد أو الباكدج في تفاصيل الحجز.
- عند التشغيل الأول، يضيف النظام عمودًا جديدًا إلى قاعدة البيانات الحالية بقيمة افتراضية صفرية للحجوزات القديمة.
