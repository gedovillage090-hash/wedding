# تحديث سيستم قاعات النسيم — أوامر الشغل

## ما تمت إضافته
- قسم «أوامر الشغل» وصلاحية مستقلة باسم `work_orders`.
- إصدار أوامر تجهيز القاعة والمطبخ والمخزن للحجز المؤكد.
- أرقام مسلسل مستقلة لأوامر القاعة والمطبخ والمخزن والمتعهدين.
- أوامر المتعهدين يمكن إسنادها لكل حجز بشكل مستقل، مع تفاصيل الخدمة وسعر داخلي لا يظهر في نسخة الطباعة.
- طباعة أمر شغل بلا أسعار أو مبالغ مالية.
- حالات الأمر: جديد، تمت الطباعة، تم التسليم، جاري التنفيذ، تم التنفيذ، ملغي.
- سجل تاريخي لإصدار الأمر وتغيير حالته.
- عند تعديل حجز مؤكد، يعاد بناء تفاصيل أوامره مع الاحتفاظ بالرقم المسلسل وزيادة رقم الإصدار، ويعود الإصدار إلى حالة «جديد» حتى تتم مراجعته وطباعته وتسليمه من جديد.
- أوامر الحجز الملغي تتحول إلى «ملغي» عند فتح صفحة أوامر الشغل.
- إصدار تلقائي للأوامر عند إنشاء حجز مرحلته «مؤكد»، أو تغيير مرحلة الحجز إلى «مؤكد»، أو تحصيل المقدم والتأمين إذا كان الحجز مؤكدًا.

## التشغيل
1. خذ نسخة احتياطية من مجلد `data` قبل استبدال ملفات البرنامج.
2. استبدل ملفات المشروع بملفات هذه النسخة مع الحفاظ على قاعدة بيانات التشغيل الفعلية.
3. شغّل `START_WINDOWS.bat` بالطريقة المعتادة.
4. سجّل الدخول بحساب لديه صلاحية `work_orders` (مدير النظام لديه صلاحية تلقائيًا).
5. افتح «التشغيل > أوامر الشغل»، واختر حجزًا مؤكدًا لإصدار أو تحديث الأوامر.
6. لإضافة متعهد لحجز، استخدم نموذج «إسناد متعهد لحجز» ثم اطبع أمره.

## ملاحظات وحدود النسخة
- ملف قاعدة البيانات داخل الحزمة هو نسخة العمل المرفقة وليس بديلًا عن قاعدة بيانات التشغيل الأحدث لديك. لا تستبدل قاعدة بياناتك الفعلية به؛ خذ ملفات الكود فقط أو احتفظ بقاعدة بياناتك الحالية.
- تفاصيل احتياجات المخزن تُحسب من روابط أصناف البوفيه الموجودة في إعدادات المخزن؛ الأصناف غير المرتبطة لن تظهر تلقائيًا في أمر المخزن.
- تم فحص صياغة `server.js` و`public/app.js` باستخدام `node --check` وفحص سلامة قاعدة البيانات المرفقة. لم يتم إجراء اختبار متصفح شامل أو اختبار طباعة فعلية في بيئة تشغيل Windows ضمن هذه الجلسة.
- هذا الإصدار ينفذ دورة أوامر الشغل الأساسية. دورة المشتريات الكاملة، وتسعير وصفات الخامات، وتكاليف الاستهلاك والهالك، ودفتر الموردين تحتاج مرحلة مستقلة لاحقة.
