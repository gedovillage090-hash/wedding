# الإصدار 53 — عرض نوع المناسبة في الإقرار

تم تغيير خانة «حفل» التي كانت تعرض اسم العروسة إلى «المناسبة»، وتعرض نوع المناسبة المسجل في الحجز (مثل فرح أو خطوبة). إذا لم يكن نوع المناسبة مسجلًا، يظهر «فرح» كقيمة افتراضية.

التحديث لا يحتاج إلى تغيير قاعدة البيانات. احتفظ بنسخة احتياطية من مجلد data قبل استبدال ملفات البرنامج.
