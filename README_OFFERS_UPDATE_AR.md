# تحديث قسم العروض — مجموعة النسيم

## ما تم إضافته
- إمكانية تسجيل أكثر من عرض نشط على نفس القاعة وفي نفس الفترة.
- ثلاثة أنواع للعروض: خصم على باكدج القاعة فقط، أو بشرط باكدج بوفيه محدد، أو بشرط البوفيه وعدد الأفراد.
- اختيار قاعة معينة أو كل القاعات، وباكدج قاعة محدد أو كل الباكدجات، وتحديد بداية ونهاية العرض.
- دعم الخصم بالنسبة المئوية أو بمبلغ ثابت.
- عند انطباق أكثر من عرض، يطبق النظام أعلى قيمة خصم مؤهلة فقط، دون تجميع الخصومات.
- أساس الخصم هو سعر باكدج القاعة فقط، وتظل باقي أجزاء الفاتورة الحالية دون تغيير مقصود.
- حقول قاعدة البيانات الجديدة تُضاف تلقائيًا عند بدء التشغيل، مع الحفاظ على العروض القديمة باعتبارها عروض باكدج قاعة فقط.

## التشغيل الآمن
1. احتفظ بنسخة احتياطية من مجلد النظام وقاعدة `data/nasim.sqlite`.
2. فك الضغط في مجلد منفصل.
3. شغّل `START_WINDOWS.bat`.
4. افتح قسم «العروض» بحساب المدير.
5. اختبر عرضًا تجريبيًا على نسخة اختبار قبل استخدامه في حجز حقيقي.

## الفحوصات التي أُجريت
- `node --check server.js`
- `node --check public/app.js`
- `npm run check`
- اختبار إضافة أعمدة ترحيل العروض على نسخة قاعدة بيانات منفصلة.
- اختبار إدخال عرض بنسبة/مبلغ ثابت والتحقق من `PRAGMA integrity_check`.

لم يتم تنفيذ اختبار متصفح شامل من جهاز المستخدم؛ لذلك يجب التحقق من عرض الخصم في الفاتورة التقديرية قبل اعتماد التغيير تشغيليًا.
