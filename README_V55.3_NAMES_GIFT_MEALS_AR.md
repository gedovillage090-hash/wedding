# الإصدار 55.3 — أسماء المطبوعات والوجبات الهدية

- أمر تشغيل المطبخ يعرض اسم باقة البوفيه فقط كما تم طلبه في الإصدار السابق.
- بند الوجبات الهدية يظهر باسم العرض المسجل إن توفر، مثل «وجبات هدية — اسم العرض»، بدل عنوان عام فقط. إذا لم يكن اسم الوجبة محفوظًا في بيانات الحجز، يظهر تنبيه واضح بأنه غير مسجل؛ لا يخترع النظام اسم وجبة.
- إضافة تنسيق موحد للأسماء المطبوعة: إزالة المسافات الزائدة فقط مع الاحتفاظ بكل كلمات الاسم، دون قص الاسم إلى الكلمة الأولى.
- لا يتم تغيير قاعدة البيانات ولا حذف أي حجوزات.

## التحديث
1. أوقف النظام وخذ نسخة احتياطية من مجلد `data`.
2. فك ضغط هذا الإصدار في مجلد منفصل.
3. انسخ ملفات البرنامج فوق ملفات النظام الحالي، ولا تستبدل مجلد `data`.
4. شغّل النظام ثم حدّث أوامر الشغل للحجز التجريبي قبل الطباعة الفعلية.

## ملاحظات
- إذا كان الاسم المحفوظ في بطاقة العميل نفسه كلمة واحدة، فسيظهر كما هو؛ أدخل الاسم الكامل في بيانات العميل أولًا حتى يظهر كاملًا في المطبوعات.
- تم فحص صياغة ملفات JavaScript، لكن لم يتم اختبار الطباعة أو رمز الدعوة على جهاز التشغيل الفعلي. اختبر رمز دعوة واحدًا من شاشة «بوابة التحقق من الدعوات» قبل الاعتماد عليه.
