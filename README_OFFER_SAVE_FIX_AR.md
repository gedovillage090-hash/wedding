# إصلاح زر حفظ العرض

تم إصلاح سبب شائع يجعل زر «حفظ العرض» يبدو وكأنه لا يعمل: حقول الخصم المخفية كانت تظل مفعلة داخل النموذج، وكان حقل المبلغ الثابت يبدأ بقيمة 0 مع حد أدنى أكبر من صفر. متصفح Chrome يرفض إرسال النموذج بسبب التحقق من حقل مخفي غير صالح، قبل وصول التنفيذ إلى معالج الحفظ.

التعديل يجعل الحقول غير المستخدمة معطلة (disabled) عند اختيار نوع الخصم أو العرض، ولا تدخل في التحقق أو البيانات المرسلة إلا الحقول المطلوبة لنوع العرض المحدد. تم الحفاظ على قاعدة البيانات المرفقة كما هي.

## التشغيل
1. احتفظ بنسخة احتياطية من مجلدك الحالي.
2. فك الضغط في مجلد جديد.
3. شغّل `START_WINDOWS.bat`.
4. افتح قسم «العروض» بحساب المدير، وجرّب حفظ عرض بنسبة مئوية ثم عرض بمبلغ ثابت، وبعدهما عرضًا يشترط بوفيه.

## الفحص
نجح `npm run check` (فحص صياغة ملفات JavaScript). لم يُجر اختبار متصفح كامل في بيئة المستخدم؛ لذلك تأكد من حفظ عرض تجريبي قبل اعتماد النسخة على البيانات الحقيقية.
