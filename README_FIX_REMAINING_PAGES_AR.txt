إصلاح الصفحات المتبقية — نظام مجموعة النسيم

الملفات داخل الحزمة:
- server.js
- public/app.js

ما تم إصلاحه:
1) مسارات المحاسبة: ملخص الحسابات، القيود، ميزان المراجعة، دفتر الأستاذ، قائمة الدخل، وحفظ القيد اليدوي.
2) التقارير العامة: GET /api/reports و GET /api/report-data.
3) أداء مبيعات الموظفين: GET /api/reports/employee-sales مع ربط سجلات البيع والتعديلات بالموظف والحجز.
4) سجل الحجوزات: GET /api/booking-status-report يرجع كائنًا يحتوي على rows بدل مصفوفة سجل الحالات الخام.
5) الدعوات الإلكترونية: البحث عن الحجوزات، تحميل البطاقات، إنشاء بطاقة QR، إلغاؤها والتحقق من الدخول.
6) حماية واجهة الدعوات من محاولة تعديل عناصر HTML بعد الانتقال إلى صفحة أخرى.

طريقة التركيب على Windows:
1) أوقف السيرفر الحالي من نافذته باستخدام Ctrl+C.
2) احتفظ بنسخة احتياطية من server.js و public\app.js الحاليين.
3) فك ضغط هذه الحزمة مباشرة داخل:
   C:\Users\Mostafa\Desktop\repair\wedding-main
   ووافق على استبدال server.js و public\app.js فقط.
4) لا تستبدل ملف .env ولا تشارك مفاتيح Supabase.
5) افتح CMD داخل مجلد المشروع ونفّذ:
   npm run check
6) إذا انتهى الفحص دون أخطاء، شغّل:
   node -r dotenv/config server.js
7) افتح http://localhost:3000 ثم نفّذ Ctrl+Shift+R.

تنبيه مهم:
- لا تحتوي الحزمة على ملف .env أو أي مفاتيح سرية.
- لا تمسح الحزمة بيانات Supabase ولا تعيد استيراد قاعدة البيانات.
- تم التحقق من صياغة server.js و public/app.js عبر node --check / npm run check.
- لم يتم اختبار الاتصال المباشر بمشروع Supabase من بيئة الإنشاء؛ بعد التشغيل المحلي اختبر الصفحات الأربع فعليًا.
