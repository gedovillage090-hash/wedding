# V28 — إصلاح الفصل بين تحصيل النقدية ويومية الخزنة

- تم فصل قراءة يومية الخزنة عن قراءة المصروفات على مستوى API.
- `GET /api/cash-journal` يتطلب صلاحية `cashbox` أو `edit_cashbox` فقط.
- شاشة المصروفات تستخدم `GET /api/cash-journal?scope=expenses` وتتطلب صلاحية `expenses` أو `edit_expenses` فقط، وتعيد قيود المصروفات فقط.
- أضيف تحديث لصلاحيات الواجهة من `/api/me` عند التنقل، لتقليل بقاء القائمة بصلاحيات قديمة بعد تغيير الصلاحيات من جلسة أخرى.
- طباعة إيصالات المصروفات مرتبطة بصلاحية المصروفات، لا بصلاحية يومية الخزنة.

## التحديث بأمان
فك الضغط في مجلد جديد، أوقف النسخة القديمة قبل التشغيل، واحتفظ بقاعدة بيانات النظام الحالية. لا تستبدل قاعدة البيانات الحالية بالقاعدة الموجودة في الأرشيف.

## تحقق مطلوب قبل التشغيل الفعلي
اختبر بحساب محدود: عند جعل `cashbox` = ممنوع يجب أن يرجع طلب `/api/cash-journal` خطأ 403 وتُمنع صفحة اليومية؛ وإذا كانت `expenses` مسموحة فقط، يجب أن تظهر المصروفات دون بقية حركات الخزنة. تم فحص صياغة JavaScript، ولم يُنفذ اختبار متصفح متكامل في هذه البيئة.
