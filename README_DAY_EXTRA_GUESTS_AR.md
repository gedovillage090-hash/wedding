# تحديث تسعير الأفراد الإضافيين للفرح النهاري

- باكدج الفرح النهاري يشمل 100 فرد.
- كل فرد يزيد عن 100 في الباكدج النهاري يُحسب بـ75 جنيهًا.
- المعادلة تطبق عند إنشاء الحجز وعند تعديل الحجز، وتظهر كذلك في تفاصيل الحجز.
- باكدجات الفترات الأخرى تحتفظ بسعر الأفراد الإضافيين السابق (60 جنيهًا للفرد) وسعة الباكدج المسجلة.
- لا يتم تعديل الإيصالات أو إضافة تحصيلات تلقائيًا.
