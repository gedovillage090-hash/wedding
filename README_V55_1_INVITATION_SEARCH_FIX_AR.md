# إصلاح البحث عن الحجز في بطاقات الدعوة — V55.1

- تحسين البحث ليعمل أثناء الكتابة وكذلك بزر البحث.
- توضيح رسالة عند عدم وجود نتائج أو حدوث خطأ.
- جعل البحث يقبل الحجوزات المؤكدة بحسب حالة الحجز أو مرحلة التأكيد، مع استبعاد الحجوزات الملغاة.
- لا تغييرات على بيانات الحجوزات أو بطاقات الدعوة الموجودة.

## التحديث
1. أوقف البرنامج.
2. خذ نسخة احتياطية من مجلد data.
3. فك ضغط الإصدار في مجلد منفصل.
4. انسخ ملفات البرنامج الجديدة فوق ملفات الإصدار السابق، مع عدم استبدال مجلد data.
5. شغّل البرنامج من جديد، ثم حدّث الصفحة تحديثًا قويًا باستخدام Ctrl+F5.
