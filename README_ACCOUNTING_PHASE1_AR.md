سيستم قاعات النسيم V46 — تأسيس المحاسبة العامة (المرحلة الأولى)

المضاف: دليل حسابات أولي، جداول الفترات المحاسبية والقيود المزدوجة، شاشة إنشاء قيد يدوي متوازن، عرض القيود، وميزان مراجعة مبدئي للفترة.

مهم جدًا: هذه مرحلة تأسيس وليست نظامًا محاسبيًا مكتملًا بعد. القيود لا تُنشأ تلقائيًا من التحصيلات والمصروفات والمخزون في هذه المرحلة، ولم تُربط الأرصدة الافتتاحية أو الضرائب أو الفروع/مراكز التكلفة. لا تعتمد التقارير كقوائم مالية رسمية قبل استكمال الربط ومراجعة المحاسب.

التشغيل: خذ نسخة احتياطية من قاعدة البيانات الحالية ومجلد data/booking-files. فك الملفات في مجلد جديد وانقل قاعدة البيانات الحالية إلى مجلد data في النسخة الجديدة قبل التشغيل. لا تستخدم قاعدة بيانات تجريبية بدل بياناتك الحالية. بعد التشغيل افتح «المحاسبة العامة». الصلاحية: accounting للقراءة وedit_accounting للتعديل، ومدير النظام لديه صلاحية الإدارة.

التحقق: فحص صياغة JavaScript فقط؛ لم يتم إجراء اختبار متصفح شامل أو مراجعة محاسبية مستقلة.
