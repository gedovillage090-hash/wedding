إصلاح حفظ تعديل الحجز — V42

- تعطيل تحقق المتصفح العام داخل وضع تعديل الحجز فقط؛ لأنه قد يمنع إرسال النموذج بسبب حقل مطلوب مخفي أو غير متعلق بالتعديل.
- إضافة تحقق واضح للحقول الأساسية ورسائل عربية عند نقص البيانات.
- الحفاظ على سعر الفرد الإضافي: 60 جنيهًا للمسائي و75 جنيهًا للنهاري.
- لا تستبدل قاعدة البيانات الحالية بقاعدة البيانات المرفقة داخل الحزمة.
- تم فحص صياغة JavaScript فقط؛ جرّب حفظ تعديل على حجز تجريبي قبل اعتماد النسخة على النظام الفعلي.
