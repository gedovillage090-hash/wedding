# صلاحيات الموظفين — قراءة أو قراءة وتعديل

- في صفحة الموظفون والصلاحيات، لكل قسم خياران: **قراءة** و**قراءة وتعديل**.
- صلاحية التعديل تمنح القراءة تلقائيًا.
- عمليات الكتابة عبر API تتحقق من صلاحية `edit_<section>`، إضافةً إلى فحوص الصلاحيات الخاصة مثل الحذف والتحصيل والموافقات.
- صلاحيات الحذف والتنبيهات تظل منفصلة عن صلاحية تعديل القسم.
- لا تمنح صلاحيات جديدة تلقائيًا للحسابات القديمة؛ راجع حساب كل موظف وحدد مستوى الوصول المناسب قبل التشغيل.
- احتفظ بنسخة احتياطية من قاعدة البيانات الحية قبل تحديث ملفات المشروع. لا تستبدل قاعدة بياناتك الحالية بقاعدة البيانات المرفقة داخل الأرشيف.

ملاحظة اختبار: تم فحص صياغة ملفات JavaScript وسلامة الأرشيف وقاعدة SQLite المرفقة. لم يتم إجراء اختبار شامل لكل شاشة وكل مسار API في المتصفح.
