# تشغيل نظام النسيم تلقائيًا بعد عودة الكهرباء

1. استخرج مجلد النظام كاملًا إلى مسار ثابت على جهاز السيرفر.
2. تأكد من تثبيت Node.js 20 أو أحدث. يلزم الإنترنت أول مرة لتثبيت المكتبات إذا لم تكن موجودة.
3. اضغط بزر الفأرة الأيمن على SETUP_AUTO_START.bat واختر Run as administrator.
4. بعد نجاح الإعداد، سيبدأ السيرفر عند بدء Windows، وسيحاول التشغيل مرة أخرى إذا توقف.
5. لا تحذف أو تنقل مجلد النظام بعد إنشاء المهمة المجدولة.
6. اختبر إعادة تشغيل الكمبيوتر وفتح النظام من جهاز موظف آخر قبل الاعتماد الفعلي.

مهم: الإعداد البرمجي يشغّل السيرفر بعد بدء Windows، لكنه لا يجبر الكمبيوتر على التشغيل بعد عودة الكهرباء. ادخل إلى BIOS/UEFI وابحث عن Restore on AC Power Loss / AC Back / After Power Failure واضبطه على Power On (تختلف التسمية حسب الجهاز). إذا لم يدعم الجهاز هذا الخيار فقد تحتاج إلى تشغيله يدويًا بعد انقطاع كهرباء كامل.

يجب أن تظل الشبكة المحلية تعمل، وأن يكون السيرفر والراوتر والسويتش موصلين بالكهرباء. UPS موصى به. هذه الآلية لا تتجاوز أعطال القرص أو قاعدة البيانات أو فشل Windows. احتفظ بنسخة احتياطية يومية من مجلد data.
