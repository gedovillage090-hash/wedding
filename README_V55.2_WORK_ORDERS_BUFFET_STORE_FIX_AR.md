# الإصدار 55.2 — تنظيم أوامر تشغيل المطبخ والمخزن

- أمر تشغيل المطبخ يعرض اسم باقة البوفيه فقط، مثل «هاي تي 1»، بدل تفصيل كل الأصناف داخل الباقة.
- أصناف المشروبات مثل المياه والماء/الماية والعصائر والكانزات والسوفت درينك لا تظهر في أمر المطبخ، وتظهر في أمر تجهيز المخزن.
- لا يتم استبدال قاعدة البيانات أو مجلد البيانات.

## التحديث
1. أوقف السيستم.
2. خذ نسخة احتياطية من مجلد `data`.
3. فك ضغط النسخة في مجلد منفصل.
4. انسخ ملفات البرنامج فوق النسخة الحالية، ولا تستبدل مجلد `data`.
5. شغّل السيستم وولّد/حدّث أوامر الشغل للحجز التجريبي للتأكد من النتيجة.
