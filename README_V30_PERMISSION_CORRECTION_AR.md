# V30 — تصحيح صلاحيات الخزنة والتحصيل

- يعكس الترحيل الخاطئ الذي أضافته V29 لمفاتيح cashbox وfinance مرة واحدة، بحيث تعود الاختيارات إلى الأسماء الظاهرة في شاشة الصلاحيات.
- تسجيل المصروف يتطلب edit_expenses تحديدًا؛ صلاحية عرض الخزنة أو التحصيل لا تمنح حق تسجيل مصروف.
- احتفظ بنسخة احتياطية من قاعدة البيانات قبل التشغيل.
- يجب إيقاف الخادم القديم بالكامل ثم تشغيل هذه النسخة، وإلا ستظل الخدمة القديمة على localhost:3000.
- لم يتم إجراء اختبار متصفح end-to-end؛ اختبر حسابًا محدود الصلاحيات بعد التشغيل.
