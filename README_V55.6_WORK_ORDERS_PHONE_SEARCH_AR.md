تحديث v55.6 — البحث عن الحجز برقم الموبايل داخل صفحة أوامر الشغل

1) افتح صفحة «أوامر الشغل».
2) اكتب رقم موبايل العميل في خانة البحث الجديدة واضغط «بحث عن الحجوزات» أو Enter.
3) ستظهر الحجوزات المؤكدة المرتبطة بالرقم مع رقم الحجز واسم العميل ورقم الموبايل والقاعة والتاريخ ووقت بداية الفرح.
4) اختر الحجز المطلوب ثم أصدر أو حدّث أوامر الشغل كالمعتاد.

التعديل لا يحذف ولا يغير الحجوزات أو أوامر الشغل الموجودة. تم فحص صياغة ملفات JavaScript، لكن لم يتم إجراء اختبار متصفح متصل بقاعدة بيانات المستخدم.
