# تحديث تقويم إشغال غرف العروسة

- إضافة خمس غرف عروسة تلقائيًا عند تشغيل النظام، دون حذف أو تعديل بيانات الحجوزات الحالية.
- يمكن اختيار صفر إلى خمس غرف عند إنشاء حجز.
- بداية إشغال الغرفة الساعة 10:00 صباحًا يوم الفرح، وتنتهي حسب وقت انتهاء الفرح المسجل بالحجز.
- يمنع الخادم إسناد الغرفة نفسها إلى حجز آخر متداخل زمنيًا.
- تقويم إشغال الغرف متاح أسبوعيًا وشهريًا داخل صفحة الحجوزات.
- للحجوزات القديمة، استخدم زر «تحديد غرف العروسة» من بطاقة الحجز لتسجيل الغرف حسب الاتفاق؛ لا تُسند الغرف تلقائيًا للحجوزات القديمة لأن الاتفاق غير معروف للنظام.
- تم إجراء فحص صياغة JavaScript وفحص سلامة SQLite وZIP. لم يُجر اختبار متصفح شامل في هذه البيئة.
