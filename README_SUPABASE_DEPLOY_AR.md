# تجهيز نسخة نظام النسيم للعمل مع Supabase

## متغيرات البيئة المطلوبة في Vercel
- `SUPABASE_URL`: رابط مشروع Supabase الصحيح.
- `SUPABASE_SERVICE_ROLE_KEY`: مفتاح الخدمة السري على السيرفر فقط. لا تضعه في ملفات الواجهة أو في متغيرات عامة.
- `JWT_SECRET`: قيمة عشوائية طويلة لا تقل عن 32 حرفًا.
- `NODE_ENV=production`

بعد تعديل Environment Variables يجب عمل Redeploy حتى يقرأها السيرفر.

## فحوصات محلية
شغّل `npm ci` ثم `npm run check`.
افتح `/api/health` بعد النشر؛ يجب أن تظهر `database: connected` و`ok: true`.

## تنبيه مهم
هذه النسخة إصلاح مرحلي لطبقة الخادم، وليست إثباتًا أن كل تدفقات العمل قد اختُبرت على قاعدة Supabase الحية. يجب اختبار تسجيل الدخول والحجوزات والتحصيل والمصروفات والمخزون وأوامر الشغل والتقارير على نسخة اختبار قبل استخدامها تشغيليًا. لا تنشر مفاتيح الخدمة أو ملفات SQL التي تحتوي على بيانات المستخدمين.
