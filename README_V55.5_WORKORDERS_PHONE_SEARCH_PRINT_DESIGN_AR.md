# الإصدار V55.5 — البحث بالموبايل وتحسين طباعة أوامر التشغيل

- إضافة رقم موبايل العميل إلى بيانات أوامر التشغيل المعروضة.
- توسيع البحث ليشمل رقم الموبايل بالإضافة إلى رقم أمر التشغيل والحجز واسم العميل والقاعة والمتعهد.
- إعادة تصميم ورقة طباعة أمر التشغيل بتنسيق واضح وحديث مناسب للطباعة على ورق A4، مع عرض اسم العميل ورقم الموبايل ومعلومات المناسبة والبنود ومساحات التوقيع.

## التحديث الآمن
1. أوقف النظام وخذ نسخة احتياطية من مجلد `data`.
2. فك ضغط النسخة في مجلد منفصل.
3. حافظ على مجلد `data` الحالي ولا تستبدله.
4. شغّل النظام وجرّب البحث برقم موبايل محفوظ، ثم اطبع أمر تشغيل تجريبي قبل الاعتماد اليومي.

تم فحص صياغة JavaScript باستخدام `node --check`. يلزم اختبار تشغيلي على قاعدة البيانات الفعلية قبل الاعتماد النهائي.
