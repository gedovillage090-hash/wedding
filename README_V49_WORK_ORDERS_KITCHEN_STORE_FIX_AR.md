# الإصدار 49 — تصحيح توزيع بنود أوامر الشغل

- أمر تشغيل المطبخ يعرض المأكولات والوجبات فقط ويستبعد المشروبات.
- أمر تجهيز المخزن يعرض المشروبات فقط مثل المياه والعصائر والمشروبات الغازية والكانزات.
- لا تغيير على قاعدة البيانات.

## التحديث
1. أوقف البرنامج وخذ نسخة احتياطية من مجلد data وملف nasim.sqlite.
2. فك الضغط وانقل ملفات المشروع دون استبدال مجلد data.
3. شغّل START_WINDOWS.bat.
4. أعد إصدار/تحديث أوامر الحجز المعني لتجديد البنود؛ الأوامر القديمة لن تتغير قبل تحديثها.

ملاحظة: التصنيف يعتمد على اسم الصنف؛ الأصناف ذات الأسماء العامة قد تحتاج إعادة تسمية واضحة. تم فحص صياغة JavaScript وسلامة ملف ZIP، ولم يُختبر على قاعدة بيانات التشغيل الفعلية.
